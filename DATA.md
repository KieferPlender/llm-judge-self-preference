# Data documentation

## Source

The sampled conversations in this repository are derived from the **LMArena human-preference dataset**:

- Dataset: `lmarena-ai/arena-human-preference-140k`
- Source: https://huggingface.co/datasets/lmarena-ai/arena-human-preference-140k
- Source license: CC BY 4.0

The source records were filtered to English, non-code, non-mathematical conversations and sampled for the judge and classifier experiments. Model responses were then transformed and evaluated as described in the thesis.

## Directory contents

| Directory | Contents |
| --- | --- |
| `data/raw/` | Sampled comparisons, classifier-training records, and baseline judge results. |
| `data/processed/` | Responses after markdown removal, Chinese back-translation, or targeted paraphrasing. |
| `data/judging_results/` | LLM judge decisions for each intervention condition. |

The raw and derived JSONL files are retained because hosted models and API aliases can change. They provide an auditable record of the exact inputs and outputs used for the reported results.

## Processing and modifications

Compared with the source dataset, the released records may include:

- filtering and sampling;
- normalized field names and study-specific metadata;
- deterministic markdown removal;
- Qwen3 back-translation through Chinese;
- Qwen3 targeted paraphrasing;
- judge responses generated by DeepSeek-R1, ChatGPT-4o, and Claude 3.5 Haiku; and
- derived human-preference and self-preference measurements.

These modifications were made by Kiefer M. Plender for the thesis experiments.

## Content notice

The data contains uncurated user prompts and model-generated responses from a public conversational benchmark. Records may contain offensive, harmful, inaccurate, biased, personal, or otherwise sensitive text. Inclusion is for research reproducibility and does not imply endorsement.

Do not use the data to identify, contact, or profile individuals. Users of the data are responsible for reviewing applicable privacy requirements, provider terms, and the source dataset license for their use case.

## Integrity

Do not edit the released JSONL artifacts in place when running a replication. Write new runs to separate files so the original thesis results remain distinguishable from later experiments.
